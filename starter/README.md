# Learner starter

Đây là skeleton domain tối thiểu có thể chạy bằng Node 22+ có TypeScript strip mode. Không phải capstone hoặc NestJS project hoàn chỉnh.

```bash
cd starter
npm test
npm run smoke
```

Ở CF-011 learner tạo NestJS workspace sau khi khóa đúng dependency versions. Code hoàn chỉnh và test suite sẽ xây dần trong Issues. Không có solution branch công khai.

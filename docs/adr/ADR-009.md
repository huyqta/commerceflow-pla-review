# ADR-009: Database topology tiết kiệm

- Trạng thái: **đề xuất/chờ review**
- Ngày: 2026-11-14

## Bối cảnh
Instance-per-service vượt budget; sharing instance vẫn là shared failure domain.

## Quyết định
Local PostgreSQL; Cloud SQL instance chia database và users riêng trong lab.

## Hệ quả và kiểm chứng
Không cross-service SQL; có kế hoạch tách instance khi cần.

## Phương án thay thế
Đánh giá tại milestone liên quan; ghi số liệu thực đo trước khi đổi quyết định.

## Step-by-step lab
1. **Đọc tình huống:** Tạo pipeline tối thiểu và pin permissions. Ghi đầu vào, đầu ra, business invariant và negative case vào `evidence/CF-029/README.md`.
2. **Chạy ví dụ thu nhỏ:** tại repository root chạy `node labs/CF-029/demo.mjs` và quan sát `MICRO_LAB_OK CF-029`. Nếu lỗi `ERR_MODULE_NOT_FOUND`, kiểm tra working directory và Node version.
3. **Đọc và chỉnh ví dụ:** mở `labs/CF-029/demo.mjs`; giải thích từng assertion. Đổi một input để assertion thất bại rồi phục hồi code, nhằm quan sát false-negative/positive và exit code.
4. **Tạo artifact sản phẩm:** `.github/workflows/ci.yml`. Tạo pipeline tối thiểu và pin permissions. Không xem micro-lab này là code production; kết nối với các artifact dependencies và bổ sung test tương ứng.
5. **Thực hiện negative test:** kiểm tra ít nhất một tình huống biên; ghi lệnh thật, expected/observed output và trạng thái trong `evidence/CF-029/README.md`. Nếu chưa có đầy đủ code từ Issues trước, đánh dấu `blocked`, không ghi `passed`.
6. **Review:** đối chiếu danh sách Acceptance Criteria, nêu rủi ro và giải thích quyết định thiết kế cho người review.

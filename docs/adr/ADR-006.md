# ADR-006: Monorepo và contract governance

- Trạng thái: **đề xuất/chờ review**
- Ngày: 2026-11-14

## Bối cảnh
Chia sẻ domain logic giữa services làm mất autonomy.

## Quyết định
pnpm monorepo với contract packages chỉ chứa DTO/schema/event envelope.

## Hệ quả và kiểm chứng
Version event, consumer-driven compatibility tests.

## Phương án thay thế
Đánh giá tại milestone liên quan; ghi số liệu thực đo trước khi đổi quyết định.

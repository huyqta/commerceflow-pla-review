# ADR-004: Cloud Run Primary, GKE Lab

- Trạng thái: **đề xuất/chờ review**
- Ngày: 2026-11-14

## Bối cảnh
GKE liên tục dễ vượt budget và lấn át mục tiêu kiến trúc.

## Quyết định
Cloud Run là deployment chính, GKE chỉ tạo trong lab ngắn.

## Hệ quả và kiểm chứng
Local kind mô phỏng trước; GKE bắt buộc teardown.

## Phương án thay thế
Đánh giá tại milestone liên quan; ghi số liệu thực đo trước khi đổi quyết định.

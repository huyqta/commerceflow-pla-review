# ADR-002: Domain ownership và clean dependency

- Trạng thái: **đề xuất/chờ review**
- Ngày: 2026-11-14

## Bối cảnh
Shared database tables và domain library dùng chung gây coupling.

## Quyết định
Mỗi bounded context sở hữu schema, domain không import framework hoặc ORM.

## Hệ quả và kiểm chứng
Dùng repository ports; kiểm tra dependency rules.

## Phương án thay thế
Đánh giá tại milestone liên quan; ghi số liệu thực đo trước khi đổi quyết định.

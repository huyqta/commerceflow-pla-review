# ADR-008: Observability và release

- Trạng thái: **đề xuất/chờ review**
- Ngày: 2026-11-14

## Bối cảnh
Không có trace khó debug Saga; latest image tag không reproducible.

## Quyết định
Structured logs correlationId, OpenTelemetry và rollback theo digest/revision.

## Hệ quả và kiểm chứng
Chạy failure drill, ghi bằng chứng rollback.

## Phương án thay thế
Đánh giá tại milestone liên quan; ghi số liệu thực đo trước khi đổi quyết định.
